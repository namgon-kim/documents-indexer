# 웹 사용자 흐름

## 문서 관리

`/`에서 파일과 임베딩 모델을 선택하고 필요한 경우 문서 유형과 고급 청킹·DPI를 지정한다. 파일은 클릭 또는 끌어놓기로 선택한다. 업로드 후 문서 카드에서 문서 입력, 읽기, 누락 확인, 내용 정리, 임베딩, 검색 준비 단계를 확인한다. 진행률은 화면에서 단계별 구간과 제공된 진행 정보를 조합해 표시하는 값이다.

문서 카드의 **처리 상세 및 작업 관리**에서 작업 기록, 누락 페이지, 원본 Office 정보, 재처리와 삭제를 확인한다. **읽은 내용으로 검색 준비**는 파싱 결과를 재사용하며, **문서 다시 읽기**는 파서를 다시 호출한다. 재처리된 내용이 기존 검색 내용보다 줄어든 경우 이전·새 내용을 비교하고 적용 여부를 선택할 수 있다.

누락 확인이 필요한 결과는 미게시 상태로 둔다. 작업 상세에서 확인할 이미지를 선택해 처리하고 누락 범위를 검토한 뒤 게시한다. 기존 검색 버전은 게시 전까지 유지된다. 단독 이미지는 사용자가 검색용 설명을 입력하면 검색 결과에서 원본을 볼 수 있다.

## 검색과 대화

`/search`에서 질의를 입력한다. **검색 조건**에서 모델, BM25/Dense/Hybrid, 선택적 재순위, 결과 수, 버전과 문서 범위를 선택한다. 결과의 **파싱 원문 보기**와 **앞뒤 문맥 보기**로 출처를 확인한다.

`/chat`에서 문서 기반 질문을 입력한다. 검색 범위 패널에서 모델·검색 방식·재순위·버전·문서를 선택한다. 답변의 번호를 누르면 해당 근거를 볼 수 있다. 대화 내용은 현재 브라우저 탭의 `sessionStorage`에 보관되며 질문과 검색된 문맥은 답변 모델로 전송된다. 모델과 추론 수준은 설정 화면에서 선택한다.

## 설정과 삽입

`/settings`는 외부 서비스, 파싱, 청크·임베딩·Qdrant, 재순위, 대화 모델, 접근·iframe, 업로드·저장 설정을 그룹별로 제공한다. 민감한 값은 재표시하지 않는다. `/embed`는 삽입용 경로이며 같은 origin 세션 또는 허용된 호스트의 일회성 코드 교환을 사용한다. 삽입 인증에는 서버 설정 권한이 없다. [iframe 계약](../user-guide/03-integration.md)
