# 대상 혼동과 검색 근거 범위: 오프라인 확인

이 문서는 #17의 Q5·Q9·Q11에 대해 사용자가 제공한 공개 PoC 청크 93개를 현재 코드에서 재색인해 확인한 결과다. 당시 실행을 복원한 기록이 아니다. 원본 Qdrant 내보내기에는 텍스트와 청크 ID가 있으나 해당 질문의 검색 후보·리랭킹·모델 입력은 없다.

`scripts/evaluate_evidence_budget.py`는 임시 BM25 색인을 만들고 현재 `_chat_evidence` 예산 처리를 호출한다. 원문이나 질의를 출력하지 않고 청크 ID·순위·포함/절단/제외 상태만 기록한다. 외부 서비스와 파서를 호출하지 않는다. 골드 ID는 제공된 문제점 보고서의 청크 번호와 ID 대응을 사용한다.

```bash
python scripts/evaluate_evidence_budget.py <청크_JSON_배열> tests/fixtures/poc_target_evidence_cases.json --candidate-limit 25 --result-limit 8 --budget 4096
python scripts/evaluate_evidence_budget.py <청크_JSON_배열> tests/fixtures/poc_target_evidence_cases.json --candidate-limit 25 --result-limit 8 --budget 32768
```

현재 BM25, 후보 25개, 선택 8개, 임시 파일명 및 빈 출처 참조 기준:

| 사례 | 지정된 정답 청크의 BM25 순위 | 4,096바이트 입력 | 32,768바이트 입력 |
|---|---|---|---|
| Q5 | 2 | 절단 | 전체 청크 포함 |
| Q9 | 1, 5 | 첫 청크 포함, 두 번째 제외 | 두 청크 포함 |
| Q11 | 2, 1 | 두 청크 포함 | 두 청크 포함 |

같은 재현에서 후보와 선택을 각각 5개, 예산을 32,768바이트로 설정하면 Q9의 두 번째 청크는 후보에 들지 않았다. 설정에 따라 후보와 실제 모델 입력이 달라질 수 있다는 예시이지 당시 설정이나 실패 원인의 증거가 아니다.

현재 서버 기본값은 검색 후보 25개, 리랭킹 결과 5개, 대화 근거 예산 32,768바이트다. 리랭킹 사용 여부와 요청 결과 수에 따라 실제 전달 경로는 달라진다. 당시 설정은 확보하지 못했다. 원본 파일명·출처·표 메타데이터를 대신해 임시 파일명과 빈 참조를 사용했으므로 이 실험의 바이트 수는 실제 요청과 일치하지 않는다. 당시 Hybrid 점수·리랭킹·표 및 이미지 확장·인접 문맥·실제 LLM 응답도 재현하지 않는다. 절단 청크의 정답 포함 여부와 포함된 청크를 모델이 올바르게 사용했는지도 판정하지 않는다.

따라서 현재 자료만으로는 #17의 오답이 후보 누락인지, 문맥 제한인지, 모델의 대상 혼동인지 확정하거나 특정 대상 판정 규칙이 필요하다고 결론 내릴 수 없다. 특정 이름이나 문자열이 없다는 이유로 근거를 필터링하면 동의어·약어와 분할 청크를 잃을 수 있어 런타임 검색·답변 규칙은 변경하지 않았다. #18의 실제 단계별 기록 또는 동일 설정으로 재실행한 결과를 확보한 뒤, 정답 근거가 모델에 전달됐는데도 대상이 혼동되는지 평가한다. 이 문서는 이슈를 자동으로 닫지 않는다.
